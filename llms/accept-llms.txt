# MIDAS API (Accept Labs)

> MIDAS is an open-source (Apache-2.0) authority-governance engine for autonomous decisions.
> Every agent or AI-system action is evaluated against explicit authority, operational
> boundaries, and execution context before it occurs, producing exactly one outcome
> (accept, escalate, reject, request_clarification) and one tamper-evident audit envelope.
> The platform is Go software with a runtime evaluation API (POST /v1/evaluate), a YAML
> control-plane, an evidence/integrity API, drift detection, an Explorer UI, and OIDC/local IAM.

This llms.txt was generated by API Evangelist from the repository catalog (no vendor-published
llms.txt exists at accept.io or midas.accept.io).

## Notes
- Auth: `Authorization: Bearer <token>` on /v1/*; dev mode MIDAS_AUTH_MODE=open. OIDC is Explorer-only.
- Idempotency: request_id per request_source; conflicting duplicate returns 409.
- Errors are `{"error":"..."}` JSON (not RFC 9457). Authority outcomes are HTTP 200.
